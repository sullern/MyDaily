# 【项目名称】—— 照片/视频日历卡片 App

> 一个用于记录每天照片、视频与日记的 Android 日历应用。  
> 本项目是一个 **Kotlin / Jetpack Compose 学习项目**，大部分代码由 AI 辅助生成，我负责需求拆解、代码审阅、功能检测、逻辑梳理与问题修正。

---

## 1. 项目简介

【项目名称】是一个本地优先的日历记录 App。用户可以在日历中按天添加多张照片或视频，并以“卡片”的形式展示当天的记录；卡片支持飞入飞出动画和视频播放速度调节；用户还可以为某张卡片或某一天写日记，并通过搜索快速定位到相关日期、卡片或日记内容；用户可获取当日天气，并自动持久化，天气信息将保留一月，目前仅支持和风天气的api;用户能自行接入ai进行有关天气对具体事件的建议。

这个项目最初的目标不是做一个商业级产品，而是通过一个**完整、可运行、有真实交互的 Android 项目**来学习 Kotlin 和现代 Android 开发。项目前期我并不熟悉 Kotlin 语法，也不熟悉 Android 项目结构，因此采用了“AI 生成大部分代码 + 人工审阅与功能验证”的协作方式。

### 项目定位

- **学习型项目**：用于学习 Kotlin、Jetpack Compose、Room、Media3、Coil、MVVM 等。
- **本地优先**：照片、视频、日记等数据默认保存在本地，不依赖云端服务。
- **AI 辅助开发**：大部分代码由 AI 生成，但经过人工审阅、运行验证和逻辑调整。
- **非生产级应用**：项目已完成主要功能闭环，但仍可能存在性能、兼容性、异常处理等方面的不足。

## 3. 功能特性

### 3.1 日历与每日记录

- 以日历形式浏览日期；
- 选择某一天查看当天的卡片记录；
- 每天可以添加多张照片或视频卡片；
- 支持卡片的新增、展示和删除；
- 卡片与日期关联，切换日期时展示对应内容。

### 3.2 照片/视频卡片

- 支持添加照片卡片和视频卡片；
- 照片使用 Coil 加载与展示；
- 视频使用 Media3 / ExoPlayer 播放；
- 卡片以列表或卡片流形式展示；
- 支持卡片飞入飞出动画，增强日期切换和卡片出现时的视觉反馈；
- 视频卡片支持播放/暂停和播放速度调节。

### 3.3 日记记录

- 支持为某张卡片写日记；
- 支持为某一天写日记；
- 日记与卡片或日期建立关联；
- 在卡片详情或日期详情中查看日记内容。

### 3.4 搜索与定位

- 支持按关键词搜索日记内容；
- 支持按日期或卡片相关信息进行搜索；
- 搜索结果可以定位到对应日期或卡片；
- 搜索无结果时展示空状态提示。

### 3.5 本地数据与隐私

- 数据默认保存在本地 Room 数据库中；
- 媒体文件通过 URI 引用本地照片/视频；
- 不默认上传用户照片、视频或日记到服务器；
- 应用卸载或清除数据后，本地记录可能丢失。

## 4. 技术栈

| 类别 | 技术 | 说明 |
|---|---|---|
| 语言 | Kotlin | 项目主要开发语言，也是本项目的学习重点 |
| 架构 | MVVM | UI、状态、业务逻辑与数据访问分层 |
| 数据库 | Room | 本地保存卡片、日记等结构化数据 |
| 图片加载 | Coil | 加载本地照片缩略图/大图 |
| 视频播放 | Media3 / ExoPlayer | 播放本地视频，支持播放速度调节 |
| 异步 | Kotlin Coroutines / Flow | 数据库查询、状态流与异步任务 |
| 导航 | Navigation Compose | 页面跳转与参数传递 |
| 构建 | Gradle Kotlin DSL | Android 项目构建 |
| 开发工具 | Android Studio | 开发、调试与运行 |

> 具体依赖版本请以项目中的 `gradle/libs.versions.toml` 或 `build.gradle.kts` 为准。
